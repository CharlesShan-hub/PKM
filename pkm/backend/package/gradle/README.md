## Basic

1. 安装: linux和mac直接用包管理器安装即可,Windows要下载源码包,找到gradle可执行文件的bin文件夹,把这个bin文件夹放到环境变量.
2. bin目录下有两个文件,一个是gradle可执行文件,另一个是批处理文件. 官方文档建议运行批处理文件,因为可以更好的适配系统, 也就是他说位的"Gradle Wrapper"方式.
3. 设置文件, 可以支持用groovy编写的`settings.gradle`或者用kotlin编写的`setting.gradle.kts`.
