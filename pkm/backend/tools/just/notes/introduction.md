# Just a Introduction

* Rust Crates: https://crates.io/crates/just
* GitHub: https://github.com/casey/just
* Dos: https://just.systems/man/zh/

1. 我对just定位的[理解](https://just.systems/man/zh/%E9%A2%84%E5%A4%87%E7%9F%A5%E8%AF%86.html)：just 是一个命令运行器，而不是一个构建系统。它只组织命令的调用，所以屏蔽了shell的区别（保留powershell，cmd，bash等），也可以支持不同的系统（windows，mac，linux等）。
2. just支持众多[渠道](https://just.systems/man/zh/%E5%AE%89%E8%A3%85%E5%8C%85.html)下载，比如cargo，scoop，homebrew，pacman，npm，conda等。
3. just拥有很多[编辑器插件](https://just.systems/man/zh/%E7%BC%96%E8%BE%91%E5%99%A8%E6%94%AF%E6%8C%81.html)，比如vim，emacs，vscode，JetBrains，sublime text等。
4. `just --version` 查看just版本，确保已经安装。
