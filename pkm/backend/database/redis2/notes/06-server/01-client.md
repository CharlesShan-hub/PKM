# 客户端

**来源**：《Redis设计与实现》第 13 章

---

## 概述

Redis 服务器为每个连接到服务器的客户端创建一个 `redisClient` 结构（客户端状态），保存客户端的各种信息。

## 客户端属性

### 1. 套接字描述符（fd）

- **普通客户端**：fd > -1，通过套接字与服务器通信
- **伪客户端**：fd = -1，用于 AOF 文件载入和 Lua 脚本执行

### 2. 名字（name）

- 默认无名字，可通过 `CLIENT SETNAME` 设置
- 通过 `CLIENT LIST` 查看所有客户端及其名字

### 3. 标志（flags）

记录客户端的角色和当前状态：

| 标志 | 含义 |
|------|------|
| REDIS_MASTER | 代表主服务器 |
| REDIS_SLAVE | 代表从服务器 |
| REDIS_MONITOR | 正在执行 MONITOR |
| REDIS_MULTI | 正在执行事务 |
| REDIS_BLOCKED | 被列表阻塞命令阻塞 |
| REDIS_DIRTY_CAS | WATCH 的键被修改 |

### 4. 输入缓冲区（querybuf）

- 类型为 SDS，保存客户端发送的命令请求
- 最大不能超过 1GB，否则会关闭客户端

### 5. 命令与命令参数（argv / argc）

- argv[0] 是要执行的命令
- argv[1..N] 是命令的参数
- argc 记录参数个数

### 6. 命令的实现函数（cmd）

- 指向命令表中对应的 redisCommand 结构

### 7. 输出缓冲区

| 类型 | 大小 | 用途 |
|------|------|------|
| 固定缓冲区（buf） | 16KB 字节数组 | 保存长度较小的回复（OK、错误等） |
| 可变缓冲区（reply） | 链表 + 字符串对象 | 保存长度较大的回复 |

### 8. 身份验证（authenticated）

- 0 表示未验证（除 AUTH 外其他命令被拒绝）
- 1 表示已通过验证

### 9. 时间属性

| 属性 | 作用 |
|------|------|
| ctime | 客户端创建时间 |
| lastinteraction | 最后一次互动时间（用于计算空转时间） |
| obuf_soft_limit_reached_time | 输出缓冲区第一次到达软性限制的时间 |

## 客户端的创建与关闭

### 普通客户端

- 连接时创建，关闭时释放
- `CLIENT KILL` 可强制关闭

### 伪客户端

- AOF 伪客户端：在载入 AOF 文件时创建，载入完成后关闭
- Lua 伪客户端：在初始化 Lua 环境时创建，服务器关闭时关闭
