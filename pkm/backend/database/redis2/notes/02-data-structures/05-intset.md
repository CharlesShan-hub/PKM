# 整数集合（Intset）

**来源**：《Redis设计与实现》第 6 章

---

## 概述

整数集合是 Redis 用于保存整数值的集合抽象数据结构，可以保存类型为 int16_t、int32_t 或 int64_t 的整数值，保证集合中无重复元素。它是集合键（Set）的底层实现之一。

## 实现

```c
typedef struct intset {
    uint32_t encoding;    // 编码方式
    uint32_t length;      // 元素数量
    int8_t contents[];    // 保存元素的数组（实际类型由 encoding 决定）
} intset;
```

- contents 数组中的元素按值的大小 **从小到大有序排列**
- 不含重复项
- encoding 决定 contents 的真正类型：
  - `INTSET_ENC_INT16`：int16_t 数组（-32768 ~ 32767）
  - `INTSET_ENC_INT32`：int32_t 数组（-2147483648 ~ 2147483647）
  - `INTSET_ENC_INT64`：int64_t 数组

## 升级

### 触发条件

向整数集合添加新元素时，如果新元素的类型比现有所有元素的类型都要长，则触发升级。

### 升级步骤

1. 根据新元素类型扩展底层数组空间
2. 将现有所有元素转换成新类型，并放置到正确位置（维持有序）
3. 将新元素添加到底层数组

### 升级后的新元素位置

- 新元素值比现有所有元素都大 → 放在末尾（index = length-1）
- 新元素值比现有所有元素都小 → 放在开头（index = 0）

### 升级的好处

1. **提升灵活性**：可以自动升级，不用担心类型错误
2. **节约内存**：不需要为所有元素使用最大的类型

## 降级

整数集合 **不支持降级**。一旦升级，编码就会保持。

## 添加新元素的时间复杂度

O(N) — 因为需要将所有现有元素类型转换并重新放置。

## 重点回顾

| 特性 | 说明 |
|------|------|
| 底层实现 | 有序数组 |
| 编码方式 | 自动升级（int16 → int32 → int64） |
| 降级 | 不支持 |
| 元素唯一性 | 不允许重复 |
| 集合键编码转换条件 | 元素都是整数且数量不多 → intset；否则 → hashtable |
