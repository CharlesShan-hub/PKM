# 监视器

**来源**：《Redis设计与实现》第 24 章

---

## 概述

监视器（Monitor）功能允许客户端通过 `MONITOR` 命令实时查看服务器处理的每个命令请求，用于调试和监控。

## 成为监视器

```
MONITOR
```

执行此命令后，当前客户端会成为监视器，之后服务器处理的所有命令都会发送给它。

服务器维护一个 `monitors` 链表：

```c
struct redisServer {
    list *monitors;  // 所有监视器客户端
};
```

## 向监视器发送命令信息

服务器在每次处理完一个命令后，在 `call()` 函数的最后，会遍历 `monitors` 链表，将命令的详细信息发送给每个监视器客户端。

发送的信息格式：

```
+1687564321.543210 [0 127.0.0.1:54321] "SET" "key" "value"
```

包含：
- UNIX 时间戳（秒.微秒）
- 数据库编号 和 客户端地址
- 命令及参数
