# 数据结构

## SDS

```c
struct sdshdr {
    int len;     // 已使用字节数（字符串长度）
    int free;    // 未使用字节数
    char buf[];  // 柔性数组，实际存储字符
};
```

1. `len`是已用长度，`free`是剩余长度，`buf[]`实际长度因为有`\0`所以是两个长度的和加一。
2. 为何内部保留c的字符串结构：为了方便的复用c的字符串函数。
3. 为何要增加长度字段：c的字符串计算长度时间复杂度O(n)，SDS用空间换时间。
4. 扩容机制1：空间预分配。修改后SDS的长度（len）将小于1MB，那么程序分配和len属性同样大小的未使用空间，这时SDS len属性的值将和free属性的值相同。举个例子，如果进行修改之后，SDS的len将变成13字节，那么程序也会分配13字节的未使用空间，SDS的buf数组的实际长度将变成13+13+1=27字节。
