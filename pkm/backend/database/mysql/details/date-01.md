### 获取当前日期和时间

- now()：获取的是执行select语句的时刻。
- sysdate()：获取的是执行sysdate()函数的时刻。

```sql
mysql> select now();
+---------------------+
| now()               |
+---------------------+
| 2026-02-21 14:56:00 |
+---------------------+
1 row in set (0.002 sec)
  
mysql> select sysdate();
+---------------------+
| sysdate()           |
+---------------------+
| 2026-02-21 14:56:04 |
+---------------------+
1 row in set (0.001 sec)
  
mysql> select sysdate(), sleep(2), now();
+---------------------+----------+---------------------+
| sysdate()           | sleep(2) | now()               |
+---------------------+----------+---------------------+
| 2026-02-21 14:57:50 |        0 | 2026-02-21 14:57:50 |
+---------------------+----------+---------------------+
1 row in set (2.070 sec)
  
mysql> select now(), sleep(2), sysdate();
+---------------------+----------+---------------------+
| now()               | sleep(2) | sysdate()           |
+---------------------+----------+---------------------+
| 2026-02-21 14:58:19 |        0 | 2026-02-21 14:58:21 |
+---------------------+----------+---------------------+
1 row in set (2.071 sec)
```
