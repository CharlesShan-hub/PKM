### rand()和rand(x)

* `rand()`生成0到1的随机浮点数。
* `rand(x)`生成0到1的随机浮点数，通过指定整数x来确定每次获取到相同的浮点值。

```sql
mysql> select rand();
+---------------------+
| rand()              |
+---------------------+
| 0.47500827114564204 |
+---------------------+
1 row in set (0.002 sec)
  
mysql> select rand(1);
+---------------------+
| rand(1)             |
+---------------------+
| 0.40540353712197724 |
+---------------------+
1 row in set (0.000 sec)
  
mysql> select rand(1);
+---------------------+
| rand(1)             |
+---------------------+
| 0.40540353712197724 |
+---------------------+
1 row in set (0.000 sec)
```
