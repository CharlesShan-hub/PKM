SQL语句是这样写的：
```sql
select * from a where id between 2 and 4 for update;
```
那么id在[2-4]区间的所有记录行被锁定，不能插入3是通过间隙锁来搞定的。不能修改或删除2和4是通过记录锁来搞定的。
