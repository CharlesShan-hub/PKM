## cast函数

cast函数用于将值从一种数据类型转换为表达式中指定的另一种数据类型

语法：`cast(值 as 数据类型)`
例如：`cast('2020-10-11' as date)`，表示将字符串'2020-10-11'转换成日期date类型。

在使用cast函数时，可用的数据类型包括：

- date：日期类型
- time：时间类型
- datetime：日期时间类型
- signed：有符号的int类型（有符号指的是正数负数）
- char：定长字符串类型
- decimal：浮点型

```sql
mysql> select cast('2000-1-1 12:10:15' as date);
+-----------------------------------+
| cast('2000-1-1 12:10:15' as date) |
+-----------------------------------+
| 2000-01-01                        |
+-----------------------------------+
1 row in set (0.000 sec)
  
mysql> select cast('2000-1-1 12:10:15' as time);
+-----------------------------------+
| cast('2000-1-1 12:10:15' as time) |
+-----------------------------------+
| 12:10:15                          |
+-----------------------------------+
1 row in set (0.000 sec)
  
mysql> select cast('2000-1-1 12:10:15' as year);
+-----------------------------------+
| cast('2000-1-1 12:10:15' as year) |
+-----------------------------------+
|                              2000 |
+-----------------------------------+
1 row in set, 1 warning (0.000 sec)
  
mysql> select cast('2000-1-1 12:10:15' as datetime);
+---------------------------------------+
| cast('2000-1-1 12:10:15' as datetime) |
+---------------------------------------+
| 2000-01-01 12:10:15                   |
+---------------------------------------+
1 row in set (0.000 sec)
  
mysql> select cast('-5.3' as signed);
+------------------------+
| cast('-5.3' as signed) |
+------------------------+
|                     -5 |
+------------------------
1 row in set, 1 warning (0.001 sec)

mysql> select cast(3.1415 as char(3));
+-------------------------+
| cast(3.1415 as char(3)) |
+-------------------------+
| 3.1                     |
+-------------------------+
1 row in set, 1 warning (0.000 sec)

mysql> select cast(3.1415 as decimal(3,2));
+------------------------------+
| cast(3.1415 as decimal(3,2)) |
+------------------------------+
|                         3.14 |
+------------------------------+
1 row in set (0.000 sec)
  
mysql> select cast(3.1415 as decimal(3,1));
+------------------------------+
| cast(3.1415 as decimal(3,1)) |
+------------------------------+
|                          3.1 |
+------------------------------+
1 row in set (0.000 sec)
```
