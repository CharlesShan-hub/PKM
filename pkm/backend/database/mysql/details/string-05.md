### 去除字符串前后空白trim

```sql
select concat(trim(' abc '), 'def');
```

```sql
mysql> select concat(trim(' abc '), 'def');
+------------------------------+
| concat(trim(' abc '), 'def') |
+------------------------------+
| abcdef                       |
+------------------------------+
1 row in set (0.001 sec)
  
mysql> select concat(' abc ', 'def');
+------------------------+
| concat(' abc ', 'def') |
+------------------------+
|  abc def               |
+------------------------+
1 row in set (0.001 sec)
```

默认是去除前后空白，也可以去除指定的前缀后缀，例如：

去除前置0

```sql
select trim(leading '0' from '000111000');
```

```shell
+------------------------------------+
| trim(leading '0' from '000111000') |
+------------------------------------+
| 111000                             |
+------------------------------------+
1 row in set (0.001 sec)
```

去除后置0

```sql
select trim(trailing '0' from '000111000');
```

```shell
+-------------------------------------+
| trim(trailing '0' from '000111000') |
+-------------------------------------+
| 000111                              |
+-------------------------------------+
1 row in set (0.001 sec)
```

前置0和后置0全部去除

```sql
select trim(both '0' from '000111000');
```

```shell
+---------------------------------+
| trim(both '0' from '000111000') |
+---------------------------------+
| 111                             |
+---------------------------------+
1 row in set (0.001 sec)
```

```sql
mysql> select ltrim('  1111 ');
+------------------+
| ltrim('  1111 ') |
+------------------+
| 1111             |
+------------------+
1 row in set (0.000 sec)
  
mysql> select rtrim('  1111 ');
+------------------+
| rtrim('  1111 ') |
+------------------+
|   1111           |
+------------------+
1 row in set (0.000 sec)
```
