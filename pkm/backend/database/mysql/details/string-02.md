
### 截取字符串substr

语法：
```sql
substr('被截取的字符串', 起始下标, 截取长度)
```

有两种写法：
* 第一种：`substr('被截取的字符串', 起始下标, 截取长度)`
* 第二种：`substr('被截取的字符串', 起始下标)`，当第三个参数“截取长度”缺失时，截取到字符串末尾
注意：起始下标从1开始，不是从0开始。（1表示从左侧开始的第一个位置，-1表示从右侧开始的第一个位置。）

练习：
```sql
mysql> select substr('12345',1,3);
+---------------------+
| substr('12345',1,3) |
+---------------------+
| 123                 |
+---------------------+
1 row in set (0.001 sec)
  
mysql> select substr('12345',2,3);
+---------------------+
| substr('12345',2,3) |
+---------------------+
| 234                 |
+---------------------+
1 row in set (0.001 sec)
  
mysql> select substr('12345',2);
+-------------------+
| substr('12345',2) |
+-------------------+
| 2345              |
+-------------------+
1 row in set (0.001 sec)
```

练习：找出员工名字中第二个字母是A的

```sql
select ename from emp where substr(ename, 2, 1) = 'A';
```

```shell
+--------+
| ename  |
+--------+
| WARD   |
| MARTIN |
| JAMES  |
+--------+
3 rows in set (0.003 sec)
```
