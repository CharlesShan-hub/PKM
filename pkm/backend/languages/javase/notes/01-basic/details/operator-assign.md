

# 赋值运算符

## 基本赋值运算符
- **简单赋值**：`=`
- **复合赋值**：`+= -= *= /= %= &= |= ^= <<= >>= >>>=`


## 复合赋值特性
```java
byte a = 2;

// 正确：复合赋值包含隐式类型转换
a += 2;  // 等价于 a = (byte)(a + 2)

// 错误：需要显式类型转换
// a = a + 2;

// 正确：显式类型转换
a = (byte)(a + 2);
```


## 三元运算符（条件运算符）
条件表达式 ? 表达式1 : 表达式2


## 优先级示例
```java
int result = 5 + 3 * 2;        // 11（乘法优先）
boolean flag = 5 > 3 && 2 < 4; // true（比较优先于逻辑与）
int value = a > b ? a : b + 1; // 相当于 a > b ? a : (b + 1)
```
