# 代码生成器/逆向工程

`MyBatis-Plus`官方为我们推荐了两种方式：

+ 第一种方式：通过自己编写代码来生成代码（**可以参考官方的代码来实现**）
+ 第二种方式：`baomidou` 专门为`IDEA`开发了`MyBatis X`插件。

首先，要安装插件`MyBatis X`
