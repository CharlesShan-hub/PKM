# 第一章（1.1节）总结：协议规范的基本概念

### 1. 什么是协议
- 协议 = 一组定义明确的消息（比特或八位组）+ 语义 + 发送规则
- 协议通常属于**协议栈**，通过分层实现复用和扩展
- 底层提供“载体服务”，上层填内容，形成分层结构

### 2. 基本概念
- **字符 vs 二进制规范**：ASN.1 采用二进制方式
- **分层与“空洞”**：下层留下“洞”，上层填写内容，实现复用和扩展
- **可扩展性**：v1 规范中预留未知材料可跳过的机制，使 v1/v2 能互通
- **抽象语法 vs 转移语法**：
  - 抽象语法：定义“要传输什么”（数据结构）
  - 转移语法：定义“怎么编码”（比特模式）
- **IDL**：类似 ASN.1 但更简单，如 CORBA IDL

### 3. 分层的优缺点
- **优点**：可复用、可扩展、可独立改进各层
- **缺点**：需要多份文档、层间“胶水”不够清晰时易出错

### 4. 五种规范方法
1. 八位组固定字段（早期协议）
2. TLV（类型-长度-值，支持扩展）
3. EDIFACT 图形语法（类似 ASN.1 但较弱）
4. BNF 字符语法（互联网常用，较冗长）
5. **ASN.1**（抽象语法 + 编码规则 + 编译器支持）
