# 第四章总结：基本数据类型与构造机制

**核心内容**：ASN.1 预定义的基本类型及其值表示法、构造机制、使用建议

---

### 1. 基本类型一览

| 类型                                               | 说明           | 关键点                                                                    |
| ------------------------------------------------ | ------------ | ---------------------------------------------------------------------- |
| **BOOLEAN**                                      | TRUE / FALSE | 全部大写                                                                   |
| **INTEGER**                                      | 整数，无界        | 可带区分值列表（不影响抽象值集），可加范围约束 `(1..56)`                                      |
| **ENUMERATED**                                   | 枚举           | 列表必需，1994 前需编号，1994 后可省略；支持 `...` 扩展                                   |
| **REAL**                                         | 实数           | 基 10 或基 2；值记法 `{mantissa, base, exponent}`；有 PLUS/MINUS-INFINITY；协议中少用 |
| **BIT STRING**                                   | 位串           | 可带命名位；值记法：`'1011'B`、`'B3'H`、`{version1}`；尾部零位无语义                       |
| **OCTET STRING**                                 | 八位组串         | 值记法：十六进制或二进制；不推荐直接用作"空洞"                                               |
| **NULL**                                         | 单值类型         | 作为占位符（TLV 结构中的标记）                                                      |
| **OBJECT IDENTIFIER**                            | 对象标识符        | 树状命名空间；全局唯一；编码紧凑；最常用的类型之一                                              |
| **ObjectDescriptor**                             | 对象描述         | 大小写混合；实际协议中几乎不用                                                        |
| **UTCTime / GeneralizedTime**                    | 日期时间         | 两位/四位年份；UTCTime 可通过滑动窗口解决 2000 年问题；可用 Z 或 ±hhmm 表示时区                   |
| **PrintableString / VisibleString / UTF8String** | 字符串          | UTF8String 推荐用于新协议                                                     |

### 2. 构造机制

| 构造器 | 说明 | 编码特点 |
|--------|------|----------|
| **SEQUENCE** | 有序列表 | 按定义顺序编码；推荐 |
| **SET** | 无序集合 | 编码顺序由实现决定；不推荐 |
| **SEQUENCE OF** | 有序重复 | 元素类型相同 |
| **SET OF** | 无序重复 | 需运行时排序；在规范编码中昂贵 |
| **CHOICE** | 互斥选择 | 值记法：`alternative:value`；无花括号 |

### 3. DEFAULT 与 OPTIONAL
- **DEFAULT**：提供默认值，编码时可省略
- **OPTIONAL**：完全可选，缺少时不传值
- BER 中 DEFAULT 值编码与否由编码器决定；规范编码（DER/PER）中必须省略默认值

### 4. 额外符号
- **选择类型** `alt1 < CHOICE-type`：从 CHOICE 中取出某个选项，极少使用
- **COMPONENTS OF**：将一个 SEQUENCE/SET 的元素"展开"到当前结构中，避免 TLV 嵌套

### 5. 标签环境
- **EXPLICIT**：嵌套 TLV，更灵活
- **IMPLICIT**：紧凑，不适用于 CHOICE
- **AUTOMATIC**：自动编号，推荐使用

### 6. 设计建议
- `SEQUENCE` 优先于 `SET`
- `UTF8String` 优先于其他字符串类型
- 给 INTEGER 加范围约束；未约束时通常假定 4 字节
- 避免直接用 BIT STRING 或 OCTET STRING 作为"空洞"；使用预定义的扩展机制
- 协议中的"空洞"（扩展点）需要明确的标识字段和异常处理机制
