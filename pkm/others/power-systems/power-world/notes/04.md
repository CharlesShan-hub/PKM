# 第四章：电能利用与发电类型

## 电能利用

### 能源的分类

* 一次能源：自然界的能源
    * 通常折合成“标准煤”或者“油当量”
    * 按照是否可再生
        * 可再生能源
            * 传统可再生：大水电，传统技术的生物能源
            * 新的可再生能源：小水电，太阳能，风能，生物质能，地热能，海洋能
        * 不可再生能源：煤炭，石油，天然气
    * 按照来源
        * 地外天体：太阳能，化石能源等等
        * 地球内部：地热能，铀等
        * 天体互相左右：潮汐能
    * 按照环保
        * 污染性
        * 清洁型：狭义(就是可再生)、广义（能源的生产消费过程对生态低污染或者无污染）
* 二次能源：直接或者间接由一次能源转化或加工出来的

### 电能利用发展历程

* 早期通信与照明
    * 19世纪上半叶：电能主要用于通信领域（电池、电缆等传递信号）；
    * 早期光源：1807年英国戴维研制碳极弧光灯；1878年美国布拉许利用弧光灯在街道和广场照明成功；
    * 1879年：爱迪生发明实用白炽灯，开创电照明新时代。
* 发电与输电技术的演进
    * 1870年：比利时格拉姆制成往复式蒸汽发电机供工厂弧光灯用电；
    * 1875年：巴黎北火车站建成世界第一个火电厂（直流供电）；
    * 1882年：上海成立电气公司（中国第一个商用发电厂）；德普勒展示高压直流输电；
    * 1885-1886年：制成交流发电机和变压器，美国建立第一个单相交流输电系统，显示交流输电优越性；
    * 1891年：德国劳芬电厂安装三相100kV交流发电机，通过三相输电线路送电至法兰克福。
* 大电网与高电压发展
    * 20世纪初至30年代：美、德等国大力发展高压输电线路（如1923年美国建成220kV线路）；
    * 1934年：美国建成432kV的287kV线路；
    * 1954年：瑞典首先建立380kV线路（采用2分裂导线）；
    * 1965年：加拿大建成765kV交流线路；苏联建成±400kV高压直流架空线路。
* 用电领域的拓展
    * 家庭生活：从收音机、电视机等耗电较小电器，发展到电冰箱、空调等，再到电气采暖和家庭全面电气化；
    * 交通运输：19世纪80年代开始电力驱动逐渐进入交通运输部门，1879年西门子和哈尔斯克展出第一条小型电车轨道，此后伦敦、巴黎等先后建成电气化地下铁道；
    * 工业生产：20世纪初，所有新建工厂都使用电动机作为动力。
* 总结与展望
    * 电力技术发展史虽短（自1875年第一座火电厂至今仅100多年），但取得了众多历史性重要成就：发电机组容量和电厂规模从小到大，技术参数和自动化水平不断提高，发电能源由单一进而多样化，输电电压等级不断提高，输电距离不断延长，电网规模日益扩大；
    * 今后，随着现代科学技术飞速发展，发电、输电、配电及电能利用技术都将在继承中得到发展，在应用中日趋完善。

## 现有发电类型

### 火力发电

1. 火力发电厂 = 燃料煤能量（x100%）、锅炉燃料能量（x88%）、涡轮机能量（x46%）、发电机能量（x99%）
2. 最后只有40%左右的能量转换成了大部分变成了热能损耗了，还会造成热污染。
3. 火力发电包含供电的和供热的（热电厂）。
4. 火力发电系统构成：燃烧系统、汽水系统、电气系统、控制系统
### 水力发电
1. 流入式水力发电
2. 调整水库式水力发电
3. 水库式发电
4. 扬水式发电
