# IEC 61850 Part 5 解读：功能和设备模型的通信要求

> **对应文件**：`860[1].5.pdf`  
> **正式标题**：IEC 61850-5 — Communication Requirements for Functions and Device Models（功能和设备模型的通信要求）  
> **页数**：约 40 页  
> **定位**：定义"什么功能需要什么样的通信性能"

---

## 一、这一章在说什么？

Part 3 说了"系统要达到什么质量"，Part 5 说的是"具体功能需要什么样的通信"。

举个例子：
- 保护跳闸功能需要**毫秒级**的 GOOSE 通信
- 监控后台读数据可以**秒级**的 MMS 通信
- 故障录波需要**微秒级同步**的 SV 采样

Part 5 就是把这些对应关系整理成表格，供设计和验收时参考。

---

## 二、功能分类：变电站里都有哪些功能？

Part 5 把变电站功能分成几大类：

```
变电站功能分类
│
├── 保护功能（Protection）
│   ├── 线路保护（距离保护、光纤差动）
│   ├── 变压器保护（差动、瓦斯、过负荷）
│   ├── 母线保护（差动保护）
│   └── 断路器保护（失灵保护）
│
├── 控制功能（Control）
│   ├── 断路器/隔离开关控制
│   ├── 变压器分接头调节
│   └── 电容器组投切
│
├── 测量功能（Measurement）
│   ├── 电流、电压、功率测量
│   ├── 电能计量
│   └── 谐波分析
│
├── 监测功能（Monitoring）
│   ├── 设备状态监测（温度、SF6压力）
│   ├── 故障录波
│   └── 事件顺序记录（SOE）
│
└── 系统功能（System）
    ├── 时间同步
    ├── 通信管理
    └── 配置管理
```

## 三、保护功能的通信要求

保护是变电站最重要的功能，对通信要求最严格。

### 线路保护（距离保护）

| 通信类型 | 要求 | 说明 |
|---------|------|------|
| GOOSE 跳闸 | < 4ms | 故障时跳相邻断路器 |
| GOOSE 联闭锁 | < 10ms | 防止误动的闭锁信号 |
| MMS 定值读写 | < 1s | 保护定值修改 |
| MMS 事件报告 | < 500ms | 保护动作事件上报 |

### 光纤差动保护

| 通信类型 | 要求 | 说明 |
|---------|------|------|
| 专用光纤通道 | < 10ms | 线路两侧电流数据交换 |
| SV 采样同步 | < 1μs | 两侧采样必须严格同步 |
| GOOSE 跳闸 | < 4ms | 本侧跳闸 + 对侧跳闸 |

**关键理解**：差动保护需要比较线路两侧的电流，如果通信延迟太大，外部故障时可能误判为内部故障。

## 四、控制功能的通信要求

控制功能相对宽松，但安全要求高。

### 断路器控制

| 通信类型 | 要求 | 说明 |
|---------|------|------|
| MMS 控制命令 | < 500ms | 遥控分合闸 |
| GOOSE 位置反馈 | < 100ms | 开关位置变化上报 |
| SBO 选择-执行 | < 10s | 选择后超时自动取消 |

**SBO 超时机制**：
```
操作员发送 Select ──→ 服务器锁定对象（10秒）
                             │
         操作员发送 Operate ──┤
                             │
         10秒内无操作 ────────→ 自动 Cancel，解锁对象
```

## 五、测量功能的通信要求

测量数据量大，但实时性要求不如保护。

### 电气量测量

| 通信类型 | 要求 | 说明 |
|---------|------|------|
| SV 采样值 | 4000Hz | 保护用高速采样 |
| MMS 测量值 | 1~10s 周期 | 监控后台刷新 |
| 报告机制 | 变化上送 | 值变化超过死区才发送 |

**死区（Deadband）机制**：
```
电压测量值：220.1kV → 220.2kV → 220.3kV
                │
                └── 变化 < 0.5%（死区），不上送

电压测量值：220.1kV → 221.5kV
                │
                └── 变化 > 0.5%，触发报告上送
```

这样可以减少网络负载，避免监控画面"刷屏"。

## 六、监测功能的通信要求

### 故障录波

| 通信类型 | 要求 | 说明 |
|---------|------|------|
| SV 采样值 | 2560Hz 或 4000Hz | 录波用高速采样 |
| GOOSE 触发 | < 4ms | 保护动作触发录波 |
| MMS 文件传输 | 分钟级 | 录波文件上传 |

**录波触发条件**：
- 保护动作触发
- 电压/电流突变触发
- 手动触发
- 开关量变位触发

### 事件顺序记录（SOE）

| 通信类型 | 要求 | 说明 |
|---------|------|------|
| 时间戳精度 | 1ms | 记录事件发生的精确时间 |
| 报告延迟 | < 100ms | 事件上送监控后台 |

**SOE 的作用**：分析故障时各设备动作的先后顺序，判断保护是否正确配合。

## 七、通信要求汇总表

| 功能类别 | 关键通信 | 延迟要求 | 可靠性要求 |
|---------|---------|---------|-----------|
| 主保护 | GOOSE | < 4ms | 99.999% |
| 后备保护 | GOOSE | < 10ms | 99.99% |
| 断路器控制 | MMS | < 500ms | 99.9% |
| 测量上送 | MMS/Report | < 1s | 99.9% |
| 故障录波 | SV + 文件 | 实时 + 分钟 | 99.9% |
| SOE | Report | < 100ms | 99.99% |
| 时间同步 | PTP/SNTP | < 1μs / < 1ms | 99.999% |

## 八、与汽车诊断的对比

| 功能 | 变电站 IEC 61850 | 汽车诊断 |
|------|-----------------|---------|
| 故障保护 | GOOSE < 4ms | 安全气囊点火 < 1ms |
| 实时控制 | MMS < 500ms | 动力控制 < 10ms |
| 数据记录 | 故障录波 2560Hz | 黑匣子数据记录 |
| 事件记录 | SOE 1ms 精度 | DTC 故障码记录 |
| 测量刷新 | 变化上送 | 周期性查询 |

**关键区别**：
- 变电站强调**事件驱动**（变化才发）
- 汽车诊断强调**周期查询**（主动去读）

## 九、总结

Part 5 的核心是"匹配"——不同功能匹配不同的通信机制：

- **保护** → GOOSE（快、可靠）
- **控制** → MMS（安全、确认）
- **测量** → Report（高效、按需）
- **录波** → SV（高速、连续）

设计系统时，先列出所有功能，再查这张表确定通信需求。
