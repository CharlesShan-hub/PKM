# 2026-04-10 工作记录

## 项目：PKMizer - Markdown 工具集

### 项目结构
- `main.py` - PySide6 GUI 主程序
- `scripts/` - 工具脚本目录
  - `markdown_splitter.py` - Markdown 分割工具
  - `image_downloader.py` - Markdown 图片下载器
  - `markdown_optimizer.py` - **新增** DeepSeek Markdown 优化工具

### 新增功能：markdown_optimizer.py
- 使用 DeepSeek API 批量优化 Markdown 文件
- 功能：将 `<font>` 标签转换为 `**加粗**`，优化 Markdown 语法
- 流程：备份原文件 → 扫描 .md 文件 → 逐个调用 API → 原地更新

### 修改：main.py 实时输出
- **重构 `ScriptRunner`**：使用 QueueWriter + queue.Queue 实现真正的实时输出
- **新增**：QTimer 每 100ms 检查队列并更新 GUI
- **新增**：停止按钮，可中断正在运行的脚本
- **修复**：`auto_fill_output_dir` 的 NoneType 错误

### 新增：API Key 自动保存
- 保存到项目根目录 `.api_key` 文件
- 启动时自动加载
- GUI 中 Show/Hide 切换显示
- Save 按钮手动保存
- 运行时自动填充到脚本参数

### 新增：.gitignore
- 屏蔽 `.api_key`、Python 缓存等

### 脚本接口规范
每个脚本需包含：
- `DESCRIPTION` - 工具描述
- `PARAM_PROMPTS` - 参数定义 {name: {label, type, default}}
- `run()` - 主函数，参数为脚本定义的参数
- `__main__` - 支持命令行运行

参数按 `PARAM_PROMPTS` 定义顺序传递。
