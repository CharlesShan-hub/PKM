已知有个升序的数组，要去插入一个元素，该数组顺序依然是升序，比如：`[10, 12, 45, 90]`，添加 23 后，数组为`[10, 12, 23, 45, 90]`

```java
public Ex{
	public static void main(String[] args){
		int[] nums = {10, 12, 45, 90};
		int[] added = new int[nums.length+1];
		int addition = 23;
		for(int i = 0; i < nums.length; i++){
			if(nums[i]>=addition){
				for(int j = 0; j < i; j++)
					added[j] = nums[j];
				added[i] = addition;
				for(int j = i; j < nums.length; j++)
					added[j+1] = nums[j];
				break;
			}
		}	
	}
}
```
