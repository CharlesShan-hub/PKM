编写类 A01，定义方法 max，实现求某个 double 数组的最大值，并返回

```java
public class Main{
	public static void main(String[] args){
		double[] ex1 = {0.0, 1.1, 2.2};
		A01 a = new A01();
		System.out.println(a.max(ex1));
	}
}
class A01{
	double max(double[] array){
		double m = array[0];
		for(int i=0; i<array.length; i++)
			if(array[i]>m)
				m = array[i];
		return m;
	}
}
```

编写类 A02，定义方法 find，实现查找某字符串数组中的元素，查找并返回索引，如果找不到返回-1

```java
public class Main{
	public static void main(String[] args){
		char[] array = {'l','o','v','e'};
		A02 a = new A02();
		System.out.println(a.find(array,'l'));
	}
}

class A02{
	int find(char[] array, char c){
		for(int i=0; i<array.length; i++)
			if(c == array[i])
				return i;
		return -1;
	}
}
```

编写类 Book，定义方法 updatePrice，实现更改某本书的价格，具体：如果价格>150，则更改为150，如果价格>100,更改为 100，否则不变

```java
public class Main{
	public static void main(String[] args){
		Book b1 = new Book();
		Book b2 = new Book(180);
		b1.updatePrice(120);
		b2.updatePrice(20);
		System.out.println(b1.price); // 100
		System.out.println(b2.price); // 180
	}
}

class Book{
	int price = 0;
	Book(){
		this(0);
	} 
	Book(int price){
		this.price = price;
	}
	public void updatePrice(int price){
		if(price>150)
			this.price = 150;
		else if(price>100)
			this.price = 100;
	}
}
```
