# 控制结构
## 顺序控制

程序从上到下逐行的执行

## 分支结构

* 单分支

  ```java
    if(condition){
      // code
    }
    ```

  * 如果只有代码块一行，可以不写括号

* 双分支

  ```java
    if(condition){
      // code1
    }else{
      // code2
    }

	// demo - 判断闰年
	int y;
	if((y%4==0 && y%100!=0) || y%%400==0){
		System.out.println("闰年");
	}
    ```

* 多分支

  ```java
    if(condition1){
      // code1
    }else if(condition2){
      // code2
    }else if(condition_n){
      // code_n
    }else{
      // code
    }
    ```

* 嵌套分支

  * 建议不要超过三层

  * 减少嵌套层数的方法

    ```java
    while(contidion){
      if(flag) continue;
      // code
    }
    ```

* Switch

  ```java
    switch(表达式){
      case 常量1:
        语句块;
        break;
      case 常量n:
        语句块;
        break;
      default:
        语句块;
        break;
    }
    ```

  * 注意`break`只退出switch

  * 一个语句块没有break进入下一个语句块继续执行

  * 表达式返回值必须是：byte、short、int、long、enum枚举，以上类型其一

    ```java
    double num = 1.1;
    switch(num){ // 错误
      case 1.1: 
        //.....
    }

	char c = 'a';
	switch(c){
		case "a": // 错误
		case 20: // 正确
	}
    ```

  * case后边的必须是常量或常量表达式，不能是变量

```java
switch(n){
	case j: // 错误，不能是变量
		//
	case 1+1: //可以，常量表达式
}
```

* 如何选择switch和if

  * 如果判断的具体数值不多，而且符合**byte、short、int、char、enum、String**六种类型，建议用switch
  * 其他情况：对区间判断，结果为boolean类型，使用if

## 循环控制

* for
	* `for(循环变量初始化; 循环条件; 循环变量迭代){ 语句块 }`
	* 初始化和变量迭代，可以用多个逗号分开
	* `for(;;)`代表死循环，两个分号不能省略

* while

  ```java
    while(循环条件){
      循环体;     
      循环变量迭代;
    }
    ```

* do...while

  ```java
    do{
      循环体;     
      循环变量迭代;
    }while(循环条件);
    ```

	```java
	// do while 统计 1 到 200 之间可以被 5 整除但不能被 3 整除的数和个数
	public classs Demo{
		public static void main(String[] args){
			int i = 1;
			int count = 0;
			do{
				if(i%5==0 && i%3!=0){
					System.out.println(i);
					count++;
				}
				i++;
			}while(i<=200);
			System.out.println("count="+i);
		}
	}
	```

* 多重循环（建议不要超过三层）

```java
// 九九乘法表
public classs Demo{
	public static void main(String[] args){
		for(int i=1; i<10; i++){
			for(int j=1; j<=i; j++)
					System.out.print(i+" * "+j+" = "+i*j+"\t");
			System.out.println();
		}
	}
}
```

```java
// 空心金字塔
public class Demo{
	public static void main(String[] args){
		int h = 5;
		for(int i=1; i<=h-1; i++){
			for(int j=0; j<h-i; j++)
				System.out.print(" ");
			System.out.print("*");
			for(int k=1;k<2*(i-1);k++)
				System.out.print(" ");
			if(i!=1)
				System.out.print("*");
			for(int j=0; j<h-i; j++)
				System.out.print(" ");
			System.out.println("");
		}
		for(int i=0; i<2*h-1;i++)
			System.out.print("*");
	}
}
```

* break

	* 标签

    ```java
    lable1:
    for(int j=0;j<4;j++){
      lable2:
      for(int i=0;i<10;i++){
        if(i==2) break lable1;
        System.out.println("i="+i+" j="+j);
      }
    }
    //print:
    //i=0 j=0
    //i=1 j=0
    ```

* continue

	* 标签：通过标签选择跳过的是哪一层循环

    ```java
    lable1:
    for(int j=0;j<4;j++){
      lable2:
      for(int i=0;i<10;i++){
        if(i==2) continue lable1;
        System.out.println("i="+i+" j="+j);
      }
    }
    //print:
    //i=0 j=0
    //i=1 j=0
    //i=0 j=1
    //i=1 j=1
    //i=0 j=2
    //i=1 j=2
    //i=0 j=3
    //i=1 j=3
    ```

* return：跳出所在方法
