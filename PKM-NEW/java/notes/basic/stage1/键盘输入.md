## 详解(DeepSeek)

Scanner 类是 Java 中一个非常实用的工具类，位于 `java.util` 包中，主要用于解析基本类型和字符串的简单文本扫描器。

### 1. Scanner 类概述

Scanner 类可以将输入（如文件、字符串或控制台输入）分解为标记（tokens），然后使用各种 next 方法将这些标记转换为不同类型的值。

#### 主要特点：

- 基于正则表达式进行文本解析
- 能够处理各种数据类型的输入
- 支持从多种输入源读取数据
- 线程不安全（不适合多线程环境）

### 2. 创建 Scanner 对象

Scanner 可以从多种输入源创建：

```java
// 从标准输入（键盘）
Scanner scanner = new Scanner(System.in);

// 从字符串
Scanner scanner = new Scanner("Hello World 123");

// 从文件
Scanner scanner = new Scanner(new File("input.txt"));
```

### 3. 常用方法

#### 基本输入方法

|方法|描述|
|---|---|
|`next()`|读取下一个字符串（以空格为分隔符）|
|`nextLine()`|读取一行文本|
|`nextInt()`|读取下一个整数|
|`nextDouble()`|读取下一个双精度浮点数|
|`nextBoolean()`|读取下一个布尔值|
|`hasNext()`|检查是否还有输入|
|`hasNextInt()`|检查下一个输入是否是整数|

#### 示例代码

```java
import java.util.Scanner;

public class ScannerExample {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        
        System.out.print("请输入您的姓名: ");
        String name = scanner.nextLine();
        
        System.out.print("请输入您的年龄: ");
        int age = scanner.nextInt();
        
        System.out.print("请输入您的身高(米): ");
        double height = scanner.nextDouble();
        
        System.out.println("姓名: " + name);
        System.out.println("年龄: " + age);
        System.out.println("身高: " + height + "米");
        
        scanner.close();
    }
}
```

### 4. 重要特性

#### 分隔符控制

Scanner 默认使用空白字符作为分隔符，但可以自定义：

```java
Scanner scanner = new Scanner("one,two,three");
scanner.useDelimiter(","); // 设置逗号为分隔符
while(scanner.hasNext()) {
    System.out.println(scanner.next());
}
```

#### 区域设置

Scanner 可以设置区域，影响数字的解析方式：

```java
Scanner scanner = new Scanner("123,45");
scanner.useLocale(Locale.FRENCH); // 法国使用逗号作为小数点
double d = scanner.nextDouble(); // 123.45
```

#### 正则表达式匹配

Scanner 支持使用正则表达式查找和匹配：

```java
Scanner scanner = new Scanner("abc123def456");
String result = scanner.findInLine("[a-z]+"); // 找到"abc"
```

### 5. 常见问题与注意事项

1. ​**​next() vs nextLine()​**​
    
    - `next()` 读取到空格或换行符前的内容
    - `nextLine()` 读取整行内容（包括空格）
2. ​**​输入类型不匹配​**​
    
    - 如果输入与预期类型不匹配（如输入字母但调用 `nextInt()`），会抛出 `InputMismatchException`
3. ​**​关闭 Scanner​**​
    
    - 使用完毕后应调用 `close()` 方法释放资源
    - 关闭关联的输入流（如 System.in）后无法再次使用
4. ​**​性能考虑​**​
    
    - 对于大量数据读取，Scanner 可能不是最高效的选择
    - 考虑使用 BufferedReader 处理大文件

### 6. 实际应用示例

#### 读取文件内容

```java
try (Scanner fileScanner = new Scanner(new File("data.txt"))) {
    while(fileScanner.hasNextLine()) {
        System.out.println(fileScanner.nextLine());
    }
} catch (FileNotFoundException e) {
    e.printStackTrace();
}
```

#### 解析复杂输入

```java
String input = "John,25,1.75;Alice,30,1.68";
Scanner scanner = new Scanner(input);
scanner.useDelimiter(";|,");

while(scanner.hasNext()) {
    String name = scanner.next();
    int age = scanner.nextInt();
    double height = scanner.nextDouble();
    System.out.printf("%s: %d岁, %.2f米\n", name, age, height);
}
```

Scanner 类是 Java 中处理输入数据的强大工具，熟练掌握它可以大大提高处理用户输入和文件解析的效率。
