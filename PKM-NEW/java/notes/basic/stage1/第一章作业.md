编写 Hello World 程序
```java
// Hello.java
public class Hello{
	public static void main(String[] args){
		System.out.println("Hello, world!");
	}
}
```

将个人的基本信息打印到控制台输出。各条信息分别占一行。
```java
// Info
public class Info{
	public static void main(String[] args){
		System.out.println("姓名\t性别\t籍贯\t住址\n顺平\t男\t四川\t北京");
	}
}
```

JDK，JRE，JVM 的关系
* JDK = JRE + 开发工具
* JRE = JVM + 运行时库

环境变量 path配置及其作用

* 环境变量的作用是为了在 dos 的任意目录使用 java 和 javac
* JAVA_HOME（jdk 主目录）
* path 增加：`%JAVA_HOME%\bin`

Java 编写步骤
* java -> javac编译 -> java 运行
