## 代码块

基本语法

```java
[修饰符]{ // 修饰符只能是 static 或者省略
	代码
}
```

```java
package ex_block;  
  
public class Test {  
    public static void main(String[] args){  
        PeopleA p1 = new PeopleA(); // Initializing  
        PeopleA p2 = new PeopleA("Jack"); // Initializing  
                // Initializing  
        PeopleB p3 = new PeopleB();  
        PeopleB p4 = new PeopleB("Jack");  
    }}  
  
class PeopleA{  
    private String name;  
    // 初始化块，用于在构造器执行之前初始化代码  
    {  
        System.out.println("Initializing");  
    }    public PeopleA(){}  
    public PeopleA(String name){  
        this.name = name;  
    }}  
  
class PeopleB{  
    private String name;  
    // 初始化块，用于在构造器执行之前初始化代码  
    static {  
        System.out.println("Initializing");  
    }    public PeopleB(){}  
    public PeopleB(String name){  
        this.name = name;  
    }}
```

1. static代码块

- **定义**：也称为静态代码块，用于对类进行初始化。
    
- **执行时机**：随着类的加载而执行，并且只会执行一次。
    
- **对比**：如果是普通代码块，每创建一个对象，就执行一次。
    

2. 类什么时候被加载

- **创建对象实例时**：使用`new`关键字创建对象时，类会被加载。
    
- **创建子类对象实例**：父类也会被加载。
    
- **使用类的静态成员时**：包括静态属性和静态方法。
