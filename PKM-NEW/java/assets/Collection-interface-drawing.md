基本方法
size(): int - 返回集合中的元素数量
isEmpty(): boolean - 判断集合是否为空
contains(Object): boolean - 判断集合是否包含指定元素
iterator(): Iterator<E> - 返回集合的迭代器(继承自Iterable接口)

数组转换
toArray(): Object[] - 将集合转换为Object数组
toArray(T[]): T[] - 将集合转换为指定类型的数组
toArray(IntFunction<T[]>): T[] - 使用数组生成函数转换为指定类型数组

元素操作
add(E): boolean - 向集合添加元素
remove(Object): boolean - 从集合移除指定元素
removeIf(Predicate<? super E>): boolean - 移除满足条件的元素
clear(): void - 清空集合

批量操作
containsAll(Collection<?>): boolean - 判断是否包含另一集合的所有元素
addAll(Collection<? extends E>): boolean - 添加另一集合的所有元素
removeAll(Collection<?>): boolean - 移除与另一集合共有的所有元素
retainAll(Collection<?>): boolean - 仅保留与另一集合共有的元素

流操作
stream(): Stream<E> - 返回顺序流
parallelStream(): Stream<E> - 返回并行流

继承自Object的方法
equals(Object): boolean - 比较集合是否相等
hashCode(): int - 返回集合的哈希码
